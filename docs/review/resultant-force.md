## Meaning

### rf-001 · multiple choice · recall

**EN:** The resultant force is…

**TA:** விளையுள் விசை என்பது…

1. the biggest of the forces acting · தாக்கும் விசைகளில் மிகப் பெரியது
2. ✅ the single force that has the same effect as all the forces acting together · தாக்கும் எல்லா விசைகளும் சேர்ந்து தரும் விளைவையே தரும் ஒற்றை விசை
3. the weight of the object · பொருளின் நிறை
4. a force that never changes motion · இயக்கத்தை ஒருபோதும் மாற்றாத விசை

Why: Several forces on one object can be replaced by one resultant force with the same combined effect.

ஏன்: ஒரு பொருளின்மீதான பல விசைகளை, அதே சேர்ந்த விளைவைத் தரும் ஒற்றை விளையுள் விசையால் பிரதியிடலாம்.

### rf-002 · true / false · recall

**EN:** More than one force can act on the same object at the same time.

**TA:** More than one force can act on the same object at the same time.

Answer: ✅ True / சரி

Why: True. For example gravity, friction and a push can all act together.

ஏன்: சரி. எடுத்துக்காட்டாக ஈர்ப்பு, உராய்வு, தள்ளுவிசை ஆகியவை ஒரே நேரத்தில் தாக்கலாம்.

### rf-003 · multiple choice · apply

**EN:** A car has stalled. One person pushes and it does not move. A second joins in, still nothing. A third joins and the car moves. This shows that…

**TA:** ஒரு கார் நின்றுவிட்டது. ஒருவர் தள்ளியும் நகரவில்லை. இரண்டாமவர் சேர்ந்தும் நகரவில்லை. மூன்றாமவர் சேர்ந்ததும் நகர்கிறது. இது காட்டுவது…

1. ✅ the forces combine into one resultant force · விசைகள் சேர்ந்து ஒரு விளையுள் விசையாகின்றன என்பதை
2. the car loses weight · கார் நிறையை இழக்கிறது என்பதை
3. each person pushes in turn · ஒவ்வொருவரும் முறைவைத்துத் தள்ளுகிறார்கள் என்பதை
4. friction disappears · உராய்வு மறைகிறது என்பதை

Why: The pushes add up, and only when the resultant is big enough does the car move.

ஏன்: தள்ளுவிசைகள் கூடி, விளையுள் போதுமான அளவு பெரிதாகும்போதே கார் நகர்கிறது.

### rf-004 · multiple choice · recall

**EN:** What decides how an object will move?

**TA:** ஒரு பொருள் எவ்வாறு இயங்கும் என்பதை நிர்ணயிப்பது எது?

1. the number of forces only · விசைகளின் எண்ணிக்கை மட்டும்
2. only its colour · அதன் நிறம் மட்டும்
3. only the biggest single force · மிகப் பெரிய தனி விசை மட்டும்
4. ✅ the resultant (unbalanced) force on it · அதன்மீதான விளையுள் (சமநிலைப்படாத) விசை

Why: It is the unbalanced force, the resultant, that changes motion (Newton’s laws).

ஏன்: இயக்கத்தை மாற்றுவது சமநிலைப்படாத விசையாகிய விளையுள்தான் (நியூற்றனின் விதிகள்).

### rf-005 · true / false · recall

**EN:** The resultant force is measured in newtons.

**TA:** The resultant force is measured in newtons.

Answer: ✅ True / சரி

Why: True. The unit of a force, and so of a resultant, is the newton (N).

ஏன்: சரி. விசையின் அலகு, ஆகவே விளையுளின் அலகும், நியூட்டன் (N).

### rf-006 · true / false · think

**EN:** The resultant of several forces is always larger than each of the forces.

**TA:** The resultant of several forces is always larger than each of the forces.

Answer: ✅ False / பிழை

Why: False. Opposite forces subtract, so the resultant can be smaller than a single force.

ஏன்: பிழை. எதிர் விசைகள் கழிவதால் விளையுள் ஒரு தனி விசையைவிடச் சிறியதாகலாம்.

### rf-012 · multiple choice · think

**EN:** An object almost never has just one force acting on it. So, to find out what it will do, we…

**TA:** ஒரு பொருளின்மீது பொதுவாக ஒரே ஒரு விசை மட்டும் தாக்குவதில்லை. அது என்ன செய்யும் என அறிய நாம்…

2. use only the first force we see · முதலில் காணும் விசையை மட்டும் பயன்படுத்துகிறோம்

ஏன்: திசை முக்கியம்: விசைகள் ஒரே கோட்டில் கூட்டப்பட்டோ கழிக்கப்பட்டோ இணைக்கப்படுகின்றன.

### rf-014 · true / false · think

**EN:** If you know only the biggest of the forces acting on an object, you can always say how it will move.

**TA:** If you know only the biggest of the forces acting on an object, you can always say how it will move.
